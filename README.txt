- services.html    Services
- reviews.html     Client feedback submission
- contact.html     Project enquiry form

DEPLOY:
1. Download and unzip this package.
2. Open your GitHub repository: https://github.com/wahidsites/wahidsites.github.io
3. Replace the existing site files with the contents of this folder (keep the repository's .git folder untouched).
4. Commit to the branch currently used by GitHub Pages (usually main).
5. Wait for GitHub Pages to publish, then visit https://wahidsites.github.io/

NOTES:
- Projects page reads public repositories from GitHub's public API and includes known project details.
- PlateCount links directly to https://wahiidhassan.pythonanywhere.com/
- Contact and feedback forms use FormSubmit and may require one-time email activation.
- Reviews are not fabricated; the page collects genuine feedback for review.
- Static multi-page site; no backend or build process required.
